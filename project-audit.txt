## Backend changes required

**Patient help alert needs an endpoint.** The app POSTs JSON to `{API}/help` and shows "Your care team was alerted"
**only on a 2xx response**. Without the endpoint the patient sees "Help has NOT been sent" plus a call button. That is
the honest behaviour, and it is what you will see until this exists. Contract + reference code: `backend/help_endpoint_example.py`
(**untested**, assumes FastAPI). If your API already has a help route, set `NEXT_PUBLIC_HELP_PATH` to it, or send me
`lib/api.ts` and the route and I will match the payload. Showing alerts to a nurse (your `/staff/help` page) is not done.

Nothing else on the backend changes. The Theater reads the same endpoints as before (`/runs`, `/runs/:id`, `/runs/:id/review`,
`/runs/:id/events`).

## Voice: what was actually wrong (found by reading `useSafetyMic.ts`, then proven with tests)

| Bug in the old code | Effect | Fix |
|---|---|---|
| Negation regex applied to the whole sentence | "no pain but I can't breathe" produced **no alert** | Negation judged locally, per phrase |
| "cannot / can not / can’t (curly)" not matched | "I cannot breathe" **silent** (old regex missed 5 of 12 emergency phrasings in my test) | Text normalised first |
| React StrictMode double-mount | stale recognizer restarted itself; two recognizers fought | Every session has a generation id; stale ones are unhooked |
| UI said "Listening" the instant `start()` was called | showed Listening while permission was pending or denied | "Listening" only after the browser reports audio |
| 20-second cooldown | a real second emergency after "I'm okay" was ignored | Episode logic + immediate re-arm on dismissal |
| `network` error → restart every 250 ms | hot loop, still said "Listening" | Capped backoff, honest "Reconnecting…" |
| Nothing audible, no real API call | alert could not truly reach anyone | Spoken reply + alarm tone + real POST |
| Demo plan call button | would have dialled `+91 00000 00000` | Placeholder numbers are never dialled |
| (my own, caught by StrictMode test) save effect overwrote saved dose ticks with empty state | **data loss on reload** | Hydration flag is state, not a ref |

Also: continuous listening restarts itself (watchdog, recycle before the browser stalls a session, wake on tab-visible/online);
the app's own speech is filtered out by text overlap rather than muting (muting made it deaf to a patient speaking over it);
a manual red **I need help now** button and a **Test without a microphone** box use the same pipeline.
Test phrases and the button send real alerts marked `source: "test"` / `"button"`.

## Live Theater

Pixel-art control room (canvas, 384×216 scaled with integer steps), driven only by real events: nodes change state from event
types, particles are spawned by `effectsFor(event)`, approval only when the polled run status is `approved`.
Shows actual model names from `extract.*.started`, field-by-field A vs B (paired by drug name, then order; differing attribute named),
reconciled result, quote verification, per-stage timings, event rate, connection/API state, patient impact.
States: standby, connecting, no-signal, live, reconnecting, stalled (>20 s without events), stream closed, API lost, reader failed,
run failed, awaiting review, approved, replay (scrub/speed), and **SIMULATED DEMO** (labelled in the pill, a banner and the connection panel).
Keys: `F` present · `R` replay · `L` live · `S` sound (off by default) · `D` demo. Presentation mode fits one 1080p screen.
Respects `prefers-reduced-motion`.

$ErrorActionPreference = "Stop"

$src = Join-Path $PSScriptRoot "web"

$backup = Join-Path $Root ("web_backup_" + (Get-Date -Format "yyyyMMdd_HHmmss"))
$count = 0
Get-ChildItem -Path $src -Recurse -File | ForEach-Object {
    $rel  = $_.FullName.Substring($src.Length).TrimStart('\', '/')
    $dest = Join-Path $web $rel
    if (Test-Path $dest) {
        $bak = Join-Path $backup $rel
        New-Item -ItemType Directory -Force -Path (Split-Path $bak) | Out-Null
        Copy-Item $dest $bak -Force
    }
    New-Item -ItemType Directory -Force -Path (Split-Path $dest) | Out-Null
    Copy-Item $_.FullName $dest -Force
    $count++
}
Write-Host "Copied $count files into $web"

from fastapi import APIRouter, File, Form, HTTPException, UploadFile

router = APIRouter(tags=["runs"])
ALLOWED = {".docx", ".pdf"}
MAX_BYTES = 15 * 1024 * 1024


class FieldAction(BaseModel):
    action: str
    attrs: Optional[dict[str, Optional[str]]] = None
    by: str = "staff"
    note: Optional[str] = None


class ApproveBody(BaseModel):
    by: str = "staff"


def _require(run_id: str) -> dict:
    if not store.exists(run_id):
        raise HTTPException(404, "run not found")
    return store.read(run_id, "meta.json")


def _items(run_id: str) -> list[ReviewField]:
    if not store.has(run_id, "review.json"):
        raise HTTPException(409, "the run has not finished processing yet")
    return [ReviewField.model_validate(x) for x in store.read(run_id, "review.json")]


@router.post("/runs")
async def create_run(
    file: UploadFile = File(...),
    patient_name: str = Form("Demo Patient"),
    language: str = Form("en"),
    phone: str = Form(""),
    guardian_name: str = Form(""),
    guardian_phone: str = Form(""),
    use_cache: bool = Form(True),
):
    ext = Path(file.filename or "").suffix.lower()
    if ext not in ALLOWED:
        raise HTTPException(415, "upload a .docx or .pdf file")
    data = await file.read()
    if len(data) > MAX_BYTES:
        raise HTTPException(413, "file is larger than 15 MB")
    if not data:
        raise HTTPException(400, "the file is empty")
    run_id = "run_" + uuid.uuid4().hex[:8]
    stored = "source" + ext
    store.dir(run_id).mkdir(parents=True, exist_ok=True)
    (store.dir(run_id) / stored).write_bytes(data)
    meta = {
        "run_id": run_id, "status": "queued", "filename": re.sub(r"[^\w.\- ]", "_", file.filename or "document" + ext),
        "stored_name": stored, "created_at": datetime.now(timezone.utc).isoformat(),
        "patient": {"name": patient_name, "language": language, "phone": phone,
                    "guardian_name": guardian_name, "guardian_phone": guardian_phone},
        "counts": None, "error": None, "approved": False,
    }
    store.write(run_id, "meta.json", meta)
    store.audit(run_id, "system", "run.created", filename=meta["filename"])
    asyncio.create_task(orchestrator.run_pipeline(run_id, use_cache))
    return {"run_id": run_id, "status": "queued"}


@router.get("/runs")
def list_runs():

@router.get("/runs/{run_id}/source")

@router.get("/runs/{run_id}/review")
def get_review(run_id: str):
    meta = _require(run_id)
    items = _items(run_id)
    doc = SourceDocument.model_validate(store.read(run_id, "document.json"))
    pending = blockers(items)
    return {"run": meta, "blocks": [b.model_dump() for b in doc.blocks],
            "fields": [i.model_dump(mode="json") for i in items],
            "blockers": pending, "can_approve": not pending and not meta["approved"]}


@router.patch("/runs/{run_id}/fields/{field_id}")
def decide_field(run_id: str, field_id: str, body: FieldAction):
    meta = _require(run_id)
    if meta["approved"]:
        raise HTTPException(409, "the plan is approved and locked")
    with store.lock(run_id):
        items = _items(run_id)
        try:
            it = apply_decision(items, field_id, body.action, body.attrs, body.by, body.note)
        except KeyError:
            raise HTTPException(404, "field not found")
        except ReviewError as e:
            raise HTTPException(422, str(e))
        store.write(run_id, "review.json", items)
        store.audit(run_id, body.by, f"field.{body.action}", field_id=field_id, attrs=body.attrs, note=body.note)
    bus.emit(run_id, Stage.REVIEW, f"review.{body.action}", {"field_id": field_id, "by": body.by})
    pending = blockers(items)
    return {"field": it.model_dump(mode="json"), "blockers": pending, "can_approve": not pending}


@router.post("/runs/{run_id}/approve")
def approve(run_id: str, body: ApproveBody):
    meta = _require(run_id)
    if meta["approved"]:
        raise HTTPException(409, "already approved")
    with store.lock(run_id):
        items = _items(run_id)
        pending = blockers(items)
        if pending:
            raise HTTPException(409, {"message": f"{len(pending)} field(s) still need a decision", "blockers": pending})
        plan = build_approved_plan(run_id, meta, items, body.by)
        store.write(run_id, "plan_v1.json", plan)
        store.update_meta(run_id, status="approved", approved=True, approved_by=body.by)
        store.audit(run_id, body.by, "plan.approved", version=1, items=len(plan["items"]))
    bus.emit(run_id, Stage.APPROVE, "plan.approved", {"version": 1, "approver": body.by, "items": len(plan["items"])})
    return plan


@router.get("/runs/{run_id}/plan")
def get_plan(run_id: str):
    _require(run_id)
    if not store.has(run_id, "plan_v1.json"):
        raise HTTPException(404, "the plan is not approved yet")
    return store.read(run_id, "plan_v1.json")

import asyncio
import json
from datetime import datetime

from fastapi import APIRouter, HTTPException
from sse_starlette.sse import EventSourceResponse

from app.schemas.events import Stage
from app.services.event_bus import RECORDINGS, bus

router = APIRouter(tags=["events"])


def _recording(run_id: str):
    return RECORDINGS / f"{run_id}.jsonl"


def _read_log(run_id: str) -> list[dict]:
    live = bus._history.get(run_id)
    if live:
        return [json.loads(e.model_dump_json()) for e in live]
    p = _recording(run_id)
    if not p.exists():
        raise HTTPException(404, "no events recorded for this run")
    return [json.loads(line) for line in p.read_text(encoding="utf-8").splitlines() if line.strip()]


@router.get("/runs/{run_id}/events/log")
def event_log(run_id: str):
    """All events so far as JSON. The theater's replay mode and tests use this."""
    return _read_log(run_id)


@router.get("/runs/{run_id}/events")
async def stream_events(run_id: str, after: int = 0, replay: bool = False, speed: float = 1.0):
    """Server-Sent Events. Live by default; replay=true re-plays the recording with its original timing."""
    has_live = bool(bus._history.get(run_id))
    if replay or (not has_live and _recording(run_id).exists()):
        events = _read_log(run_id)

        async def replay_gen():
            prev = None
            for ev in events:
                if ev["seq"] <= after:
                    continue
                ts = datetime.fromisoformat(ev["ts"].replace("Z", "+00:00"))
                if prev is not None:
                    await asyncio.sleep(min((ts - prev).total_seconds() / max(speed, 0.1), 1.5))
                prev = ts
                yield {"id": str(ev["seq"]), "data": json.dumps(ev)}

        return EventSourceResponse(replay_gen())

    async def live_gen():
        async for ev in bus.stream(run_id, after):
            yield {"id": str(ev.seq), "data": ev.model_dump_json()}

    return EventSourceResponse(live_gen())

"""Tiny file-based store: one folder per run under data/runs. Zero infrastructure, easy to inspect."""
import json
import os
import threading
from datetime import datetime, timezone
from pathlib import Path
from typing import Any

from pydantic import BaseModel

ROOT = Path(__file__).resolve().parents[3]


def runs_dir() -> Path:
    return Path(os.getenv("RR_RUNS_DIR", ROOT / "data" / "runs"))


def _dump(obj: Any):
    if isinstance(obj, BaseModel):
        return obj.model_dump(mode="json")
    if isinstance(obj, list):
        return [_dump(o) for o in obj]
    if isinstance(obj, dict):
        return {k: _dump(v) for k, v in obj.items()}
    return obj


class RunStore:
    def __init__(self) -> None:
        self._locks: dict[str, threading.RLock] = {}

    def lock(self, run_id: str) -> threading.RLock:
        return self._locks.setdefault(run_id, threading.RLock())

    def dir(self, run_id: str) -> Path:
        return runs_dir() / run_id

    def exists(self, run_id: str) -> bool:
        return (self.dir(run_id) / "meta.json").exists()

    def write(self, run_id: str, name: str, obj: Any) -> None:
        d = self.dir(run_id)
        d.mkdir(parents=True, exist_ok=True)
        with self.lock(run_id):
            (d / name).write_text(json.dumps(_dump(obj), indent=2, ensure_ascii=False), encoding="utf-8")

    def read(self, run_id: str, name: str) -> Any:
        return json.loads((self.dir(run_id) / name).read_text(encoding="utf-8"))

    def has(self, run_id: str, name: str) -> bool:
        return (self.dir(run_id) / name).exists()

    def update_meta(self, run_id: str, **changes) -> dict:
        with self.lock(run_id):
            meta = self.read(run_id, "meta.json")
            meta.update(changes)
            self.write(run_id, "meta.json", meta)
            return meta

    def audit(self, run_id: str, actor: str, action: str, **detail) -> None:
        line = json.dumps({"ts": datetime.now(timezone.utc).isoformat(), "actor": actor,
                           "action": action, **detail}, ensure_ascii=False)
        with self.lock(run_id):
            with open(self.dir(run_id) / "audit.jsonl", "a", encoding="utf-8") as f:
                f.write(line + "\n")

    def list_runs(self) -> list[dict]:
        base = runs_dir()
        if not base.exists():
            return []
        metas = [json.loads(p.read_text(encoding="utf-8")) for p in base.glob("*/meta.json")]
        return sorted(metas, key=lambda m: m.get("created_at", ""), reverse=True)


store = RunStore()

    """Read KEY=VALUE lines directly, ignoring hidden characters."""
    values = {}

export class ApiError extends Error {
  status: number;
  detail: unknown;
  constructor(status: number, detail: unknown) {
    super(typeof detail === "string" ? detail : `Request failed (${status})`);
    this.status = status;
    this.detail = detail;
  }
}

async function parse<T>(res: Response): Promise<T> {
  if (!res.ok) {
    let detail: unknown = res.statusText;
    try {
      detail = (await res.json()).detail ?? detail;
    } catch {
      /* body was not JSON */
    }
    if (typeof detail === "object" && detail !== null && "message" in detail) {
      throw new ApiError(res.status, (detail as { message: string }).message);
    }
    throw new ApiError(res.status, detail);
  }
  return (await res.json()) as T;
}

  createRun: (form: FormData) =>

const fmt = (h: number) => {
  const hh = ((h % 24) + 24) % 24;
  return `${hh % 12 === 0 ? 12 : hh % 12}:00 ${hh < 12 ? "AM" : "PM"}`;
};

/** Turns the wording of a frequency into clock times. Anything unclear (as needed, until review) gets no times. */
export function timesFor(freq: string | null): string[] {
  const f = (freq ?? "").toLowerCase();
  if (!f || /as needed|prn|when required/.test(f)) return [];
  const every = f.match(/every\s+(\d{1,2})\s*(?:hours?|hrs?|h)\b/);
  if (every) {
    const n = Number(every[1]);
    if (n >= 3 && n <= 24) return Array.from({ length: Math.ceil(24 / n) }, (_, i) => fmt(8 + i * n)).slice(0, Math.floor(24 / n) || 1);
  }
  if (/(four|4)\s*times|qid/.test(f)) return [8, 12, 16, 20].map(fmt);
  if (/(three|3)\s*times|tid|thrice/.test(f)) return [8, 14, 20].map(fmt);
  if (/twice|(two|2)\s*times|bid|b\.i\.d/.test(f)) return [8, 20].map(fmt);
  if (/once|daily|every day|(one|1)\s*time|at night|morning/.test(f)) return [/night|bedtime/.test(f) ? 21 : 8].map(fmt);
  return [];
}

export function toMinutes(t: string): number {
  const m = t.match(/(\d+):(\d+)\s*(AM|PM)/);
  if (!m) return 0;
  return (Number(m[1]) % 12) * 60 + Number(m[2]) + (m[3] === "PM" ? 720 : 0);
}

export function planFromReview(d: ReviewData): PlanView {
  const plan: PlanView = {
    patientName: d.run.patient.name, phone: d.run.patient.phone, meds: [], followUps: [], contacts: [], demo: false,
    instructions: { wound_care: [], activity: [], diet: [], warning_signs: [] },
  };
  for (const it of d.fields) {
    const f = it.field;
    if (it.decision?.action === "reject") continue;
    if (f.status === "rejected" && it.decision?.action !== "edit" && it.decision?.action !== "confirm") continue;
    const a = currentAttrs(it);
    if (!a) continue;
    if (f.category === "medications") {
      plan.meds.push({ id: f.field_id, name: a.name ?? "Medicine", dose: a.dose ?? null, frequency: a.frequency ?? null, duration: a.duration ?? null, times: timesFor(a.frequency ?? null) });
    } else if (f.category === "follow_ups") {
      plan.followUps.push({ id: f.field_id, what: a.what ?? "Follow-up", when: a.when ?? null, where: a.where ?? null });
    } else if (f.category === "contacts") {
      if (a.value) plan.contacts.push({ label: a.label ?? "Care team", value: a.value });
    } else if (f.category === "wound_care" || f.category === "activity" || f.category === "diet") {
      if (a.instruction) plan.instructions[f.category].push(a.instruction);
    } else if (f.category === "warning_signs") {
      if (a.text) plan.instructions.warning_signs.push(a.text);
    }
  }
  return plan;
}

import { useEffect, useRef, useState } from "react";
import { Icon } from "@/components/staff/icons";

import type { Severity } from "@/lib/voice/phrases";

export interface HelpAlertProps {
  heard: string;
  label: string;
  severity: Severity;
  source: "voice" | "button" | "test";
  phone: string;
  /** False for empty or placeholder numbers: the call button is replaced by an honest explanation. */
  phoneDialable: boolean;
  demo: boolean;
  status: HelpStatus;
  openedAt: number;
  /** The person tried to close while the care team had not been notified. */
  confirmClose: boolean;
  soundBlocked: boolean;
  emergencyNumber?: string;
  onRetry: () => void;
  onClose: () => void;
}

const mmss = (ms: number) => `${String(Math.floor(ms / 60000)).padStart(2, "0")}:${String(Math.floor((ms % 60000) / 1000)).padStart(2, "0")}`;
const clockTime = (t: number) => new Date(t).toLocaleTimeString(undefined, { hour: "2-digit", minute: "2-digit" });

/** Full-screen emergency view. It only says "sent" when the backend really answered 2xx. */
export default function HelpAlert(p: HelpAlertProps) {
  const root = useRef<HTMLDivElement>(null);
  const [elapsed, setElapsed] = useState(0);

  useEffect(() => { try { navigator.vibrate?.([300, 150, 300, 150, 300]); } catch { /* not supported */ } }, []);
  useEffect(() => {
    const id = setInterval(() => setElapsed(Date.now() - p.openedAt), 1000);
    return () => clearInterval(id);
  }, [p.openedAt]);

  // Focus the safest action on open and keep keyboard focus inside the dialog.
  useEffect(() => {
    const el = root.current;
    if (!el) return;
    const prev = document.activeElement as HTMLElement | null;
    (el.querySelector<HTMLElement>("[data-first]") ?? el).focus();
    const trap = (e: KeyboardEvent) => {
      if (e.key !== "Tab") return;
      const f = Array.from(el.querySelectorAll<HTMLElement>("a[href],button:not([disabled])"));
      if (!f.length) return;
      const first = f[0], last = f[f.length - 1];
      if (e.shiftKey && document.activeElement === first) { e.preventDefault(); last.focus(); }
      else if (!e.shiftKey && document.activeElement === last) { e.preventDefault(); first.focus(); }
    };
    el.addEventListener("keydown", trap);
    return () => { el.removeEventListener("keydown", trap); prev?.focus?.(); };
  }, []);

  const s = p.status;
  const critical = p.severity === "critical";
  const phoneLine = p.phone.replace(/[^\d+]/g, "");

  return (
    <div className={`pt-alert${critical ? " is-critical" : ""}`} role="alertdialog" aria-modal="true" aria-labelledby="pt-alert-h" aria-describedby="pt-alert-d" ref={root} tabIndex={-1}>

        <p id="pt-alert-d">I heard: “{p.heard}” <small className="pt-alert-tag">{p.source === "voice" ? "voice" : p.source === "test" ? "test phrase" : "button"} · {mmss(elapsed)}</small></p>

        {/* The truth about whether the care team has been told. */}
        <div className={`pt-alert-status is-${s.kind}`} role="status" aria-live="assertive">
          {s.kind === "sending" && <><i className="pt-spin-w" /> <span>Alerting your care team{s.attempt > 1 ? ` (attempt ${s.attempt})` : ""}…</span></>}
          {s.kind === "sent" && <><Icon.check size={20} /> <span><b>Your care team was alerted</b> at {clockTime(s.at)}.{p.demo ? " (Demo plan)" : ""}</span></>}
          {s.kind === "failed" && <><Icon.x size={20} /> <span><b>Help has NOT been sent.</b> {s.reason} Call your care team now.</span></>}
          {s.kind === "idle" && <span>Not sent yet.</span>}

        {p.emergencyNumber && <a className="pt-btn pt-btn--red pt-alert-btn" href={`tel:${p.emergencyNumber}`}><Icon.phone size={22} /> Call emergency services ({p.emergencyNumber})</a>}

import Link from "next/link";
import { usePathname } from "next/navigation";
import { MotionConfig } from "framer-motion";
import { Suspense, createContext, useContext, useState, type ReactNode } from "react";
import { Icon } from "./icons";

/** The top-bar search text, shared with whichever page wants to filter by it. */
const SearchCtx = createContext("");
export const useSearch = () => useContext(SearchCtx);

const NAV = [
  { href: "/staff", label: "Dashboard", icon: Icon.grid, active: (p: string) => p === "/staff" || p.startsWith("/staff/runs") },
  { href: "/staff/upload", label: "New discharge", icon: Icon.upload, active: (p: string) => p.startsWith("/staff/upload") },
  { href: "/staff/help", label: "Help requests", icon: Icon.bell, active: (p: string) => p.startsWith("/staff/help") },
];

function Nav({ path }: { path: string }) {
  return (
    <nav className="rr-nav" aria-label="Main">
      {NAV.map((n) => (
        <Link key={n.href} href={n.href} className={`rr-nav-item${n.active(path) ? " is-active" : ""}`}>
          <n.icon size={18} />
          {n.label}
        </Link>
      ))}
    </nav>
  );
}

/** usePathname needs a Suspense boundary in production builds on dynamic routes. */
function ActiveNav() {
  return <Nav path={usePathname() ?? ""} />;
}

export default function Shell({ children }: { children: ReactNode }) {
  const [q, setQ] = useState("");
  return (
    <MotionConfig reducedMotion="user">
      <div className="rr">
        <aside className="rr-side">
          <Link href="/staff" className="rr-brand">
            <span className="rr-brand-mark"><Icon.heart size={19} /></span>
            <span>
              <b>RecoverRight</b>
              <small>From discharge to recovery</small>
            </span>
          </Link>
          <Suspense fallback={<Nav path="" />}>
            <ActiveNav />
          </Suspense>
          <div className="rr-side-foot">
            <p>Prototype with fictional data only. Nothing here is medical advice.</p>
          </div>
        </aside>
        <main className="rr-main">
          <header className="cc-top">
            <label className="cc-search">
              <Icon.search size={17} />
              <input value={q} onChange={(e) => setQ(e.target.value)} placeholder="Search patients or documents" aria-label="Search patients or documents" />
            </label>
            <div className="cc-top-right">
              <div className="cc-user">
                <span className="cc-avatar">CT</span>
                <div><b>Care team</b><small>Nurse coordinator</small></div>
              </div>
            </div>
          </header>
          <SearchCtx.Provider value={q}>{children}</SearchCtx.Provider>
        </main>
      </div>
    </MotionConfig>
  );
}

"""
REFERENCE ONLY, NOT TESTED. I could not see your API code and FastAPI was not available where this was written.
It documents the contract the patient app's help alert expects, so the backend can implement it.

The web app (web/lib/voice/help.ts) POSTs JSON to  {API}{NEXT_PUBLIC_HELP_PATH, default "/help"}
and says "Your care team was alerted" ONLY if the response status is 2xx. Anything else is shown to the
patient as "Help has NOT been sent".

Adapt names and storage to your app. Anything that shows these to a nurse (e.g. your /staff/help page) is a
separate piece of work: the staff console was deliberately not modified.
"""
from datetime import datetime, timezone
from typing import Literal

from fastapi import APIRouter
from pydantic import BaseModel

router = APIRouter()
HELP_REQUESTS: list[dict] = []  # replace with your real storage


class HelpPayload(BaseModel):
    token: str                                   # the patient link token (run id)
    patient_name: str = ""
    heard: str                                   # what was said, or "I pressed the help button"
    severity: Literal["critical", "concern"]
    label: str = ""                              # e.g. "trouble breathing"
    source: Literal["voice", "button", "test"] = "voice"   # staff can filter out "test"
    demo: bool = False                           # True for the /p/demo plan
    client_time: str = ""


@router.post("/help", status_code=201)
def create_help_request(p: HelpPayload):
    item = {**p.model_dump(), "id": len(HELP_REQUESTS) + 1,
            "received_at": datetime.now(timezone.utc).isoformat(), "status": "open"}
    HELP_REQUESTS.append(item)
    return {"id": item["id"]}


@router.get("/help")
def list_help_requests():
    return list(reversed(HELP_REQUESTS))
